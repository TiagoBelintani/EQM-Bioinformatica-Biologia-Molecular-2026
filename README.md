# EQM - Bioinformática e Biologia Molecular - 2026

Repositório da disciplina EQM - Bioinformática e Biologia Molecular.

## Organização

- `notebooks/` — notebooks utilizados nas práticas
- `datasets/` — arquivos de dados didáticos
- `scripts/` — scripts utilizados nas análises
- `docs/` — documentação complementar

## Dataset principal

As práticas utilizarão dados públicos de UCEs do gênero *Hypochilus*, associados ao BioProject PRJNA760946.

O fluxo geral da disciplina será:

NCBI / SRA → FASTQ → controle de qualidade → trimming → montagem de novo → contigs → identificação de UCEs → FASTA de loci UCE
